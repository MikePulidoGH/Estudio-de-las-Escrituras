# Guía interactiva: Leer con fundamento

Este paquete contiene una guía interactiva en español sobre el protocolo de estudio del audio. No necesita bibliotecas, imágenes ni archivos externos: los estilos y las interacciones están incluidos en `index.html`.

## Publicarla con GitHub Pages

1. Creá un repositorio nuevo en GitHub.
2. Subí `index.html` a la raíz del repositorio. También podés incluir este `README.md`.
3. En el repositorio, entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**. Seleccioná la rama principal (por ejemplo, `main`) y la carpeta **`/(root)`**; guardá los cambios.
5. Cuando GitHub termine el despliegue, abrí la dirección que aparece en esa misma sección de Pages.

El archivo `index.html` debe permanecer en la raíz elegida para que la dirección principal del sitio muestre la guía.
